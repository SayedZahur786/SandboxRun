SANDBOXRUN / PREVIEW POLICY

Preview terms

Updated 19 November 2026

SandboxRun is an experimental developer tool for running short Python and JavaScript snippets with explicit resource budgets. Using the preview means accepting the limitations described here and in the security model.

Permitted use

Use the service only for code and data you are authorized to process. Do not use it to attack others, steal information, send abusive traffic, circumvent service limits, or disrupt availability. Local adversarial testing of your own deployment is encouraged. Coordinate testing of a hosted deployment with its operator.

Preview limitations

The service is provided as available, without a service-level commitment or a guarantee that execution is error-free or suitable for a particular purpose. Availability, language compatibility, runtime versions, limits, and API behavior may change. The operator may reject requests or suspend access to protect the service.

WebAssembly containment is not a guarantee against every vulnerability. Do not rely on this preview as the sole control for sensitive or high-impact workloads. Review returned data before using it in another tool or agent.

Your code and results

You retain your rights to code and data you submit. By sending a request, you authorize the service to process that material to execute the request and return its result. You are responsible for having the necessary rights and for your downstream use of results.

Credentials and data

Protect your API key and rotate it if exposed. The browser workbench does not persist the key. Read the privacy notice before submitting data. No paid subscription, production support commitment, or long-term data retention service is offered by this preview.
